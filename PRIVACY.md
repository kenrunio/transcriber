# Privacy policy

Transcriber runs entirely on your computer. Your recordings, transcripts,
speaker names and edits never leave it.

This program will not transfer any information to other networked systems
unless specifically requested by the user or the person installing or
operating it.

## When it connects to the internet

Only in these cases, each started by you:

| When | Where it connects | What is sent |
|---|---|---|
| You download a model on the Models page | Hugging Face (huggingface.co) for speech, speaker and punctuation models | An ordinary download request for that model's files |
| You download GPU support on the Models page | PyPI (pypi.org, files.pythonhosted.org) for NVIDIA's libraries | An ordinary download request for those files |
| You have agreed to update checks (the app asks once; change it in Settings) | GitHub (api.github.com), once a day when the app starts | A request for the latest release, with the app's version in the request header |
| You click Download, What's new or Project page | GitHub, in your web browser | Whatever your browser sends when opening a page |

Like any download, these requests reach the service with your computer's IP
address. Transcriber sends no account details, no usage statistics and no
content of your files, and it has no telemetry.

Those services have their own privacy policies:
[Hugging Face](https://huggingface.co/privacy),
[PyPI / Python Software Foundation](https://policies.python.org/pypi.org/Privacy-Notice/),
[GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
